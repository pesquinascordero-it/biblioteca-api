# 📚 Biblioteca

Aplicación para gestionar los libros de una biblioteca, dividida en dos partes:

- **`frontend/`**: la página web (HTML, CSS y JavaScript sin frameworks).
- **`backend/`**: la API REST en Node.js *(en construcción)*.

Es un proyecto de aprendizaje para entender cómo se comunican un frontend y un backend a través de HTTP.

## Cómo abrir el frontend

Abre `frontend/index.html` con el navegador (doble clic).

- Con **Modo demo** activado, la página usa datos de prueba y funciona sin servidor.
- Con **Modo demo** desactivado, se conecta a la API en `http://localhost:3000`.

La parte de abajo, **Peticiones HTTP**, muestra cada petición que hace la página (método, ruta y código de estado), para ver qué pasa por debajo.
